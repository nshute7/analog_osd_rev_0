# analog_osd_rev_0
Analog on-screen display (OSD) board designed in KiCad for MAX7456E derivatives.

This layout was influenced heavily by original work found at https://github.com/night-ghost/minimosd-extra/tree/master/board.

The contribution of this project is to re-implement the analog first-person view (FPV) hardware using a recent parts list available through PCB houses such as JLCPCB.
